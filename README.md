# four_model_classiffication
# 🌾 Teff Grain Filling Period Classifier

Classification of **grain filling period** for teff (*Eragrostis tef*) accessions into **Short**, **Medium**, and **Long** classes, using phenological, geographic, soil, and bioclimatic data.

## 📋 About

| Item | Detail |
|------|--------|
| **Dataset** | `teff.xlsx` — 2,084 accessions × 65 columns |
| **Target** | `Gfpc` — Grain Filling Period Class (1=Short, 2=Medium, 3=Long) |
| **Features** | 55 numeric features (phenological dates/traits, lat/long, altitude, soil pH, 19 current + 19 RCP4.5-2070 bioclimatic variables) |
| **Models** | Logistic Regression, Random Forest, XGBoost, SVM |
| **Best Model** | XGBoost — 98.1% test accuracy, 97.1% CV accuracy |
| **Deployment** | Streamlit Cloud (`app.py`) |
| **Training source of truth** | `TeffProject.ipynb` (Google Colab notebook — this is what actually produced the shipped model/artifacts) |

## 🚀 Deploy on Streamlit Cloud

1. Push this repository to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repository
4. Set **Main file path** to `app.py`
5. Click **Deploy**

`app.py` looks for `xgb_teff_model.pkl`, `label_encoder.pkl`, and `features.pkl` in the repo root first, and falls back to a `models/` + `artifacts/` layout if those aren't present.

## 📊 Reproducing Training (Google Colab)

1. Open `TeffProject.ipynb` in Google Colab
2. Upload `teff.xlsx` when prompted (cell 7)
3. Run all cells — cleaning, EDA, training, evaluation, export happen in sequence
4. Download `features.pkl`, `xgb_teff_model.pkl`, `label_encoder.pkl` (cell 34)
5. Push those files to GitHub alongside `app.py` and `requirements.txt`

## ⚠️ Known Limitation: Target Leakage

The feature set (`features.pkl` → `numeric_features`) currently includes `Hdate`, `Mdate`, `Edate`, `Hdatec`, `Mdatec`, `Edatec`, `PCHdate`, and `PCMdate` — heading and maturity dates. Grain filling period is arithmetically derived from the gap between heading and maturity dates, so these columns leak the target directly into the feature set. This is almost certainly why accuracy is at 98%; it should **not** be read as a genuine geo-climatic predictive signal.

A leakage-free run (excluding these date columns, using only geographic/climate/soil predictors) benchmarks closer to **~55% accuracy / ~0.445 macro-F1** with Random Forest — a more realistic ceiling for this prediction task. If this project or report is used for academic purposes, this limitation should be stated explicitly, and a leakage-free feature set should be considered for the headline results.
